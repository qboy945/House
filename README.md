# House｜房仲一鍵文案神器

填一次物件資料，快速整理成四種平台風格的文案草稿，方便房仲或物件介紹者複製後再編修使用。

**正式網址：<https://qboy945.github.io/House/>**

直接用手機或電腦瀏覽器開啟即可，不需安裝，也不需 API key。

## 第二個專案：房仲一鍵出圖＋文案

在同一儲存庫的 `/studio/` 路徑，提供另一個獨立工具：填一次物件資料，同時產出**社群圖卡**（4 種版型，可上傳自己的房屋照片套版）與上述四種平台文案。

**網址：<https://qboy945.github.io/House/studio/>**

與第一版各自獨立、互不影響；第一版的網址與功能維持不變。

圖卡由瀏覽器本機以 Canvas 繪製，**不使用 AI 生成圖片**，也不會上傳照片到任何伺服器；照片僅在使用者自己的裝置內處理。圖片僅供社群曝光使用，不能取代 591／樂屋網等平台的正式刊登主圖，也不能當作產權或屋況證明。

## 四種文案格式

| 頁面分頁 | 適用情境 |
| --- | --- |
| FB 社團爆款 | Facebook 社團或貼文，條列物件資訊、特色與聯絡方式 |
| 591規格 | 591／樂屋網等物件介紹，採基本資料與亮點的條列格式 |
| LINE 推坑 | LINE 私訊分享，以較口語的方式介紹物件與邀約看屋 |
| IG吸睛短文 | Instagram／小紅書風格短文，搭配表情符號與主題標籤 |

這些是文案格式，不是平台串接；工具不會自動刊登，也不保證符合各平台的全部刊登規定。

## 如何使用

1. 開啟正式網址，填入社區／案名／地段、開價（萬元）、格局、總建坪及樓層／總樓高。
2. 格局可從常用選單選擇「套房」、「1房1廳1衛」、「2房1廳1衛」、「2房2廳1衛」、「3房2廳2衛」或「4房2廳2衛」。選取後仍可直接修改文字，例如改成「2房2廳1衛1陽台」；也可選「自行輸入」。選擇「不選擇」或「自行輸入」不會清空已有格局。
3. 僅勾選已確認的物件特色，並補充其他備註、經紀人稱呼與電話／LINE ID。
4. 按「✨ 一鍵生成 4 大平台文案」，再切換分頁查看不同格式。
5. 按「📋 複製此文案」複製目前分頁，在要使用的平台或文字編輯器中修改並核對後再刊登。若修改了上方資料，請重新按生成按鈕更新草稿。

也可以使用結果區的「🖨️ 列印 / 儲存 PDF」，開啟瀏覽器列印功能；能否儲存 PDF 依裝置與瀏覽器而定。

### 想先試用？

按「⚡ 帶入示範物件」，再按生成按鈕即可查看效果。示範會帶入表單資料並清除已選特色標籤；**示範資料不代表真實待售物件，請勿直接當成真實廣告刊登。**

### 無法自動複製？

剪貼簿功能可能受到瀏覽器權限或使用環境限制。若自動複製失敗，可在結果文字上長按選取，或以滑鼠選取後手動複製。

## 運作方式與資料處理

- 這是**固定本機模板工具，不是 AI 生成服務**；文案由 `index.html` 中的 JavaScript 模板與使用者輸入組合而成。
- 不需要 AI 帳號、API key 或模型服務，也不會自動查證物件資訊。
- 輸入資料與文案組合在使用者的瀏覽器內處理，工具程式不會將表單輸入傳送至後端或外部服務。
- 網站由 GitHub Pages 提供；開啟網站仍會產生一般網站連線，主機服務可能依其政策處理連線資訊。上述說明不代表網站連線完全沒有紀錄。

## 刊登前請確認

輸出內容只是草稿。請逐項核對物件名稱、價格、坪數及其計算範圍、格局、樓層、屋況、產權、車位與各項特色，刪除不適用或未經證實的敘述，並補上正確聯絡方式。

請依實際刊登地區及平台要求，補齊法定與平台必要資訊（例如適用的經紀業、經紀人或證照資訊）。本工具的欄位與模板不代表已涵蓋所有必要揭露事項，也不會代為審核廣告。

## 專案結構與基本維護

- `index.html`：第一版（文案轉換機）單一網頁檔，包含 HTML 表單、CSS 樣式與 JavaScript 文案模板及互動功能。
- `studio/index.html`：第二版（圖卡＋文案合併工具）單一網頁檔，含 Canvas 圖卡繪製、四種版型與四平台文案模板。
- `README.md`：工具介紹、使用方式與維護說明。

兩個版本互不依賴，修改其中一個不會影響另一個。維護時請分別確認各自的功能。

目前不需要套件安裝或建置流程。下載 `index.html` 後可直接以瀏覽器開啟，檢查表單與文案效果；本機開啟時的剪貼簿行為可能與正式 HTTPS 網站不同。

維護時，介面與欄位位於 HTML，樣式位於 `<style>`，文案模板主要位於 `generateAll()`。修改後先確認示範填入、格局選擇／自由修改、四種文案切換及複製功能，再提交至 GitHub Pages 所設定的發布來源；Pages 部署完成後即可由正式網址查看。若調整發布方式，請在儲存庫的 **Settings → Pages** 確認來源設定。
